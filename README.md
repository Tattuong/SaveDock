# SaveDock

Save a link, note, or file, then give it a next step: Read, Try, Buy, or Reference.

Package: `com.SaveDockMNG.SaveDock`

Remote config: [N315.json](https://api2.blwsmartware.net/N315.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

## IAP product IDs

| ID | Type |
| --- | --- |
| `sd_pack_1` … `sd_pack_10` | Consumable coins |
| `sd_remove_ads` | Non-consumable |
| `sd_pro` | Non-consumable, more than 8 saves |
